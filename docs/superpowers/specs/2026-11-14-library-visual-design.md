# 制作库与工作台视觉统一

用户指出制作库与工作台的美术风格差异过大。以现有工作台的 `docs/DESIGN.md` 和 `app.css :root` 为基准，让制作库成为同一应用的项目入口。

方案：移除制作库专属深色变量和硬编码深色表面，复用冷中性灰、单一蓝色强调、11/12/13/15px 字级、3/4px 圆角、细边框和标准控件。收紧大标题、留白、卡片与筛选控件，去掉渐变和卡片上浮。保留舰船分组、单船多方案、响应式布局和所有数据操作。

考虑过仅改背景颜色，但字体、间距、按钮和弹窗仍会割裂；也不引入第二套主题或改造工作台。上述选择属于实现判断，基于用户要求直接推进，不重复请求确认。

验收：制作库首页、舰船方案页、筛选弹层及编辑/导入等表单与工作台使用相同视觉语言；窄屏可用，状态/错误/禁用/焦点清晰；已有筛选、打开预览和编辑行为不变。
