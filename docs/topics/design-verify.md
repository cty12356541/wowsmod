# design-verify: 层 7 验收(`wowsmod design-template acceptance`)

1. 同角度对比: 从参考里挑 3–6 帧(舷侧/艏斜/艉斜/俯视/近景), 在 `wowsmod preview` 工作台(或浏览器引擎 `render`)里出同角度图并排, soft 图不算; 再进港用固定机位截图并排。工作台时间线应能回看每一步。
2. 港口: 白天、夜间(港口时段随机, 多进几次或换港口)、远景(看 LOD 与可读性)、近景(锯齿/拉伸)。
3. 日志: python.log 有 `registerShipMod … done`, 无新错误。
4. 结束: `wowsmod uninstall <项目>`, res_mods 复原。

**判定**: 按拆解清单逐行打勾; 每个不达标项写明退回哪一层(轮廓不对→层 3; 图案不像→层 4; 发光位置/强度→层 5; 特效→层 6; 证据不足→层 1)。连续 3 轮仍不达标的项, 写进报告说明原因(多半是缺工具能力)。
**自评**: 把参考帧和港口截图并排给一个没看过的人, 他会说是同一套吗?

## 预热
反复出图自检前先 `wowsmod render --warm <项目>`(常驻实例, 每张约 1 秒, 改动后自动增量重载); 冷启动每张要十几秒。`wowsmod render status <项目>` 看是否就绪。
