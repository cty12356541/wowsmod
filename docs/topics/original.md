# original: 原创(没有参考对象)

与 theme 共用**设计书**模板和执行流程(`wowsmod help design`、`help theme`), 只有第 1 步不同: 设计语言要从零设计。

## 第 1 步: 概念探索(设计书 §1 original)
1. 收集用户的关键词 / 情绪 / 用途(竞技低调? 展示夸张?)。
2. AI 提出 **≥3 个风格方向**, 每个配情绪板(色卡 + 纹样示意 + 材质示意)或同角度概念预览(`render` + 大色块), 方向之间要真正不同(如: 硬边几何迷彩 / 有机流线 / 纹章礼仪)。
3. 用户选定(或混合)一个方向后, 共同定义设计语言卡(§2): 配色与比例、纹样母题、线条风格、材质感、徽记; 再定 §3 的额外模型、发光、特效。
4. 之后与 theme 相同: §4 克制/强化/夸张三档预览 → 多轮 `design-book revise` → 用户定稿 `finalize` → 分层执行 → 对比验收。

## 原创特有的检查
- 块面色之间明度差够大(港口会把暗色压黑、饱和色提亮, 见 `help recolor`)。
- 纹样边界顺船体走向(斜切、沿舷弧), 不用规则网格条纹; 单靠细线不算图案。
- 发光只做点缀, 可见面积有上限(写进设计语言卡)。

## 示例(仅示例)
勃艮第 "深蓝 + 信号橙": 艏艉大斜切橙块 + 炮塔顶橙带 + 块边暖白细光。首轮直接执行、没有概念探索与定稿, 港口里深蓝偏亮偏饱和 —— 按本流程应在 §4 预览阶段就对照港口标定调整。
