# original: 原创(只有风格描述)

没有参考也没有主题, 目标是"好看、可读、不脏"。先读 `wowsmod help design`。

## 设计原则
1. 大色块优先: 先定 2–3 个明度差明显的块面(深/中/浅), 块面边界顺着船体走向(斜切、沿舷弧), 不用规则网格条纹。
2. 发光是点缀: 发光像素占可见舷侧面积 ≤ 5%(看 bake-ref/lineart 输出的 coverage), 只放在块面边缘、炮塔棱、上层建筑横向棱线。
3. 远近都成立: 远看(`render --width 800`)靠块面成立, 近看(进港 v4_near)靠细线与原贴图细节; 底色用 `tex recolor --to-color` 保留明暗细节(--detail 1)。
4. 昼夜都检查: 港口白天看块面, 发光在阴影面和暗底色上最明显; 暗底色要按 design 的港口补偿加亮。

## 流程
1. 把风格描述翻成参数表: 底色/块面色/发光色、线的走向、发光占比上限。
2. 出一个方案: 侧视设计图(同框, 见 replicate 第 2–3 步) → `bake-ref` 键色抠遮罩 → `tex recolor` / `glow`。
3. `render --engine soft --yaw 35 --pitch 14` 和 `--view side` 自查; 进港截图。
4. 细化 1–2 轮: 每轮只改一类问题(构图/明度/发光量)。

## 停止条件
自检清单全部通过且发光占比在上限内; 或 2 轮细化后用户满意。
