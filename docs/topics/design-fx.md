# design-fx: 层 6 特效(炮口火焰/开火烟/烟囱烟/曳光)

- 在层 1 记录参考里的: 炮口火焰颜色/形状、开火烟、烟囱烟颜色、曳光颜色。
- 文件层: 特效定义编译在 `content/assets.bin`, 不能直接改参数; **能改的是粒子/尾迹贴图**: `particles/animated/*`(烟/火/炮口闪光序列帧)、`trails/*`(开火烟、曳光)。用 `wowsmod find "particles/animated/*"`、`wowsmod find "trails/*"` 查, `extract` → `tex recolor`/替换 → `tex import --like` 写回。
- 某船用哪种特效: 船 .visual 里的 `HP_FX_Smoke_*`、炮塔 `HP_gunFire*` 挂点 + GameParams 引用(规划中的 `wowsmod fx ship-effects`)。
- **风险: 这些贴图全局共享, 会影响所有船**(以及其它共用同一贴图的烟/火)。不能只改一艘船。只做纯视觉, 不碰烟雾弹半径/时长等玩法数值(服务器权威, 可能违规)。
- 验证: 烟囱烟港口可见 → 港口截图; 炮口火焰/开火烟/曳光只在开火时出现 → 需要训练房, **未经用户明确授权不要进**, 未验证就在报告里写"未实证"。

**完成标准**: 每项特效改动列出了被影响的全局贴图、已告知用户全局影响; 港口可验证的已截图; 需训练房的已获授权验证或标"未实证"。
**自评**: 用户换其它船时这个特效还能接受吗?
