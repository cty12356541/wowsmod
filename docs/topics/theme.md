# theme: 主题设计(给一个主题, 如角色/作品)

没有逐像素参考, 目标是"一眼认出主题"。先读 `wowsmod help design`。

## 1 提取主题元素(写成表)
- 主色 2–3 个 + 强调色 1 个(写 #RRGGBB), 标注哪个做底、哪个做块面、哪个发光
- 标志图形 1–2 个(纹样/符号/轮廓), 能否简化成线或块
- 发光色与发光位置偏好(主题里"会发光"的东西)
- 不做: 文字、版权 logo、需要新模型的东西(翅膀等)

## 2 2–3 个概念
每个概念 = 一张侧视设计图(同 replicate 第 2–3 步: `render --view side --width 4096 --json` 取 frame, 在同框透明 PNG 上画)+ 一句话说明差异(如 A: 大色块 / B: 线条为主 / C: 只改炮塔与上层)。
概念只在**复制出来的项目**里做(`mod init` 新项目或复制目录), 各自 `bake-ref` → `tex recolor` / `glow` → `render --engine soft --yaw 35 --pitch 14`, 把三张图并排给用户选。

## 3 细化选中的概念
- 标志图形放在最显眼且不被遮挡的位置: 舷侧中前部、主炮塔侧面/顶面、烟囱。
- 远景检查: `render --width 800` 缩小看还能不能认出主题; 认不出就加大块面、减少细线。
- 进港截图(白天), 再按 design 自检清单过一遍。

## 停止条件
用户选定概念后最多 2 轮细化; 或自检清单全部通过。
