# theme: 主题设计(用户只给一个角色 + 作品)

AI 主动探索该角色的设计语言和应有元素, 与用户一起迭代出**设计书**, 定稿后再执行。共用流程见 `wowsmod help design`; 本模式与 original 只有第 1 步不同。

## 流程
0. `wowsmod design-book init <项目> --mode theme --title "<角色> 主题"`
1. **资料收集**(设计书 §1 theme): 官方立绘、设定图、游戏/动画截图、同人、已有涂装; 存进参考图集目录, 每张注明来源。B 站视频可用 `scripts/ref/ref_frames.py` 抽帧。
2. **设计语言卡**(§2): 主/辅/点缀色及面积比例(从参考图取色, 不凭印象)、标志纹样与符号、线条风格、材质感、专属道具/徽记。每项写依据图。
3. **映射到船**(§3): 逐部件 —— 大面配色、纹样位置与尺度、发光、额外模型(翼/光环/徽章…, 写形状/挂点/尺寸)、炮火与烟是否随主题(全局贴图, 见 design-fx)。部件名用 `wowsmod model list` / render 查。标可行性。
4. **2~3 个方向**(§4): 克制 / 主题强化 / 夸张, 每个出同角度 `render` 预览(层 3 大形 + 层 4 大图案即可, 不做细节)。
5. 设计书初稿交用户 → 用户提意见 → `design-book revise --note "<意见摘要>"` → 改稿出新预览, 多轮。
6. 用户明确定稿 → `design-book finalize --by 用户` → 按层 3–7 执行, 每层对照设计书自查 → 对比验收(预览/参考图 vs 港口)。

## 自评
- 不看船名, 只看远景截图, 熟悉该作品的人能认出是谁吗?
- 设计语言卡每一项都有参考图依据吗? 有没有只用了"主色"而丢了纹样/道具?
- 版权: 不直接搬官方 logo 文字; 立绘类图案注明来源, 不分发他人作品。

## 示例(仅示例)
勃艮第 + 某游戏角色: 首轮只做了"电路走线 / 光点 / 装甲分色"三种线与块面, 没有资料收集与设计语言卡, 也没有角色道具类额外模型 → 只能算方向预览, 不是设计书。
