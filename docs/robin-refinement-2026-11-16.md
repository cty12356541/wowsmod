# 勃艮第 × 知更鸟：原纹理清理与局部精修

本轮优先解决原船木纹、脏污、斑驳凹凸和水渍反光残留，同时精修主炮装甲盖、烟囱环冠及其支撑。保留紫蓝白金配色、星纹和原有装配。原项目只读；修改制作在独立的“勃艮第 × 知更鸟 · 精修 01”方案中。

## 制作内容

- 以当前 DDS 为底稿，清理原底色的亮度残差和法线细纹；保留主题色边、星纹、机械接缝和结构性遮蔽。原船大面积木纹、脏污不再透过涂装。
- 主炮盖板重新贴合原炮塔，增加浅倒角和窄接缝。修复肩带 UV 误采到 AO 黑区的问题，保留原回转骨骼与权重。
- 烟囱宽环冠增加折边、细青色内沿与四个实际接触下方结构的支座，收短会侵入副炮运动空间的飘带。高悬于前部的另一处光环未扩展。
- 副炮炮管根部的蓝色护套改为连续圆润边界，保留三个炮孔和紫色中线。
- 青色发光区域收敛色相，保留发光覆盖和强度数据；没有以全局曝光或灯光修改掩盖资产问题。

## 实机水渍问题与因果验证

首次进入构建 `8871067` 的黑桃城夜港后，原主炮斜顶、艏部锚机周边与艉甲板仍有不规则水渍状亮斑。当前客户端 shader 的 normal.B 同时参与 detail 索引和天气门控；关闭 detail 材质强度并不能关闭这条天气分支。

从本机当前客户端的 shader 和港口配置确认门控关系后，制作了只改变 B 通道的独立实验。六个 DDS/分卷中，解码后的 R/G/A、目标区域外的像素与压缩块、其余模型及材质文件保持一致。相同夜港、相同设置下的第二次实拍显示，三处大斑明显消退，星纹、紫带、金边和几何分级保留。镜头通过相同操作尽量复现，不能称为逐参数相同的游戏相机。

两轮均未更改舰船涂装；只读检查确认装备“白色”消耗型涂装。最终扩展覆盖船体、上层建筑和三类炮塔，包含已重涂的深蓝防尘罩。目标涂装面使用 W=0/detail8；7 个直接关联 MFM、29 个 visual/LOD 绑定的 detail 三项影响均为 0。只修改 5 张 normal 的 12 个分卷，57 级 mip 的解码 R/G/A 完全不变。

主炮 11 级 mip 的目标覆盖均为 100%，避免为了保留罩上的旧积水效果而在远距离恢复整级旧斑。其他材质的清晰机械开口仍保留；低 mip 中已混合的极小机械足迹按记录的覆盖比例处理，不声称每个混合 texel 的 B 都与原版一致。防尘罩的真实 RG 褶皱、颜色和遮蔽不变。

最终包再次进入黑桃城夜港和海洋日港：主炮顶与艏艉甲板的大片旧反光没有重现，近中远拉动未见旧斑跳回；炮衣褶皱、152 副炮三暗孔及环冠承托均可辨，白紫金蓝的材质衔接自然。日志确认 26 条模型替换、1 次注册完成、无相关加载错误。结论限于构建 8871067、记录的设置与机位；未进入战斗或测试所有港口。报告和 8 张实拍位于 `port-final/`。

## 工作台材质修正

修正已核查的五种舰船 fx 的 MG 解释：现代材质 R 为 gloss、G 为 metal；两个旧式发光 fx 使用独立 remap、F0 和 diffuse 公式。fx 纳入材质与程序缓存，保留显式 0 参数。albedo、normal、wire、mask 诊断视图不再经过 Bloom。实际观图确认现代炮位颜色层级、金边区分以及实机船体/炮位衔接均可接受，因此未为未知的运行时 gamma 盲改 MG。

这是已证基础材质量的修正。运行时 gamma 和 SRGB view 未捕获，预览 gamma=1 是明确的编译缺省近似；Three 的 BRDF、内部粗糙度限制、天气和后处理仍与游戏不同。emissive 视图保留少量基础画面作为定位参照，不是纯发光遮罩。全局灯光、曝光、tone 和 Bloom 强度没有重调。

## 验证证据与边界

- 几何：目标资源的 LOD 0–3、14 个炮位、116 个硬点与非目标资源保持。按真实骨骼和当前 GameParams 离散检查 95,997 个姿态，含禁射区内的回转经过姿态；新烟囱部件未出现检测到的相交。采样为 1°，不代表完整连续空间、后坐或真实战斗逻辑的证明。
- 贴图：全部 mip 解码、DDS 格式/分卷、法线与 MG 语义、关联 MFM、保护区域及源项目散列分别检查。早期下采样造成 packed 通道漂移的问题已修复，不能只用顶层 mip 的结果代替全链验证。
- 静态近景：主炮肩带、护套、环冠与支座均经过截图复审及返修。新旧工作台对照必须使用同一渲染器和逐字段相同的相机，不能混用修正材质前后的图片。
- 副炮白盖浅紫中线附近的轻微灰阶，经颜色与 AO 分离检查不能认定为旧污，保留其结构阴影；没有为追求全白而抹掉接缝与浅紫线。
- 工作台正常界面操作看到主炮回转及抬升至 22.1°、三座 152 副炮抬升至 46.9°，精修盖板随炮塔回转。主炮齐射出现烟迹和装填，副炮出现炮口白焰。主炮瞬时闪焰与完整后坐行程未清晰捕捉，不能宣称逐帧验收过这些过程。
- 前端 CPU 回归 140 项、TypeScript、前端与 Windows release 构建通过。17 组真实 GPU shader 数值读回全部通过，无编译错误；四个诊断通道在 Bloom 开关前后逐像素一致，final 仍有预期的 Bloom 差异。移入仓库的 GPU 回归工具已在最终项目上再次实际运行并通过。
