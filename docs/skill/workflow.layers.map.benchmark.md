# workflow.layers.map.benchmark: 对标评审(例子并排打分)
上级: workflow.layers.map
下级: 无
---
**何时**: 主题/复刻在方向预览前后; 层 3 外带、层 4 涂装自认「好看了」之前。无合适例子则写明「无对标」并降低完成标准, 不可假装过审。
**输入**: ≥1 个同船或同题材例子(视频关键帧/`refs` ANALYSIS/原包拆解); 本项目工作台图; 可选 `book/BENCHMARK.md`。
**做法**:
1. 表列例子的主/辅/点缀色及占比、明度差、图案分区与密度、外带造型(分层/倒角/镶边/发光线/尺度)。
2. 与本项目同角度并排(`scripts/ref/compare.py`), 每维 1–5 分 + 一句差距。
3. **门槛**: 配色、图案、外带(若设计书有外带)均 ≥3 才可进下一层; 否则退回层 2/3/4。
4. 结论写进设计书 §4/§5 与 changelog。
**完成标准**: 有对照表+并排图; 分数与退回层写清; 未达门槛不装港、不定稿。
**根因提醒**: 只查「有没有文件/有没有雕像」不算审美验收(见 r18)。
