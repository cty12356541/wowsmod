# workflow.layers.map.benchmark: 有依据的同角对比
上级: workflow.layers.map
下级: 无
---
**用途**：参考帮助发现差距，不提供通用配色、几何或评分门槛。无对应参考时按设计意图验收，写明“无直接对标”。
1. 选择能解释本次目标的参考帧，与项目同机位/范围并排(`scripts/ref/compare.py`)；记录昼夜、look 和无法对齐处。
2. 分开看轮廓/布局、图案覆盖与笔触、明暗色彩/材质、发光；有模型才比较模型，不把参考里的所有物件变成新增要求。
3. `role_share` 等测量需同遮罩/分类与可比视角。数字用于说明面积与明暗变化；照片、预览与港口光照不同，不能直接等同比例或颜色。
4. 每项写“符合意图 / 有差距 / 未验证”及依据。可用项目自定评分帮助排序，但不把固定分数当跨项目通过线。有意偏离要写设计理由。
5. 差距回到对应层；小样/结果与下一步写项目复盘。通用问题才成为指引改进候选，见 `workflow.review`。
