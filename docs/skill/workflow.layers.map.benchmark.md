# workflow.layers.map.benchmark: 对标评审(同角并排打分)
上级: workflow.layers.map
下级: 无
---
**定位(参照不钉死)**: 标杆评分/role_share 只给参考区间与差距方向; 主题语言、配色比例、图案可以自有设计, 偏离时写理由。
**何时**: 方向预览后; 层 3/4 自认完成前。无例子则写「无对标」并降标, 不可假装过审。
**输入**: 标杆同视角帧; 本项目同角工作台图; `role_share`/`part_colors` 结果; 有外带时 teardown 表。
**做法**:
1. **同角强制**: 舷/舷斜/侧/俯/夜 能对上的都并排(`compare.py`), 禁止只交「有图」。
2. 配色维: 主色块% / 暗色% / L_span / 中灰%(role_share); 本色是否来自角色部位。
3. 几何维: 外带大件对等、剪影远景可读、无原版灰部件清单。
4. 每维 1–5 + 一句差距; 分数衡量「设计意图是否达成」, 与标杆的差距若是有意设计(写理由)不扣分; 某维 <3 且非有意 → 退回该层。
5. 结论进设计书与 changelog。
**完成标准**: 同角并排图+分数+(有意偏离的理由 / 退回层)。
**根因(r18/r20)**: 只查文件/无雕像、或不同角自评, 会假过。
