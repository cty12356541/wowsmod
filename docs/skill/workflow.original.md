# workflow.original: 原创(只有风格/情绪)
上级: workflow
下级: 无
---
**目标**: 从零定义设计语言, 其余与 theme 相同。
**输入**: 关键词/情绪/用途、目标船。**完成标准**: 用户选定方向且设计语言卡写完, 之后同 theme。
**第 1 步**: 收集关键词/情绪/用途 → 提 ≥3 个真正不同的风格方向, 每个写主/辅/点缀色(港口色先 `port-albedo` 换算)并用 `design-preview` 出同机位粗样(只换大面色 + 一处图案, 这就是 §4, 之后不再另出三档)→ 用户选定或混合 → 写设计语言卡 → §3 逐部件映射(同 `workflow.theme` 第 3 步)→ 层 3–7。
**风格包**: 已有包贴近就采用; 定下的新风格想复用时按 `wowsmod help styles` 的结构新建一个包。
**原创特有检查**: 块面明度差够大(港口压暗/提亮, 见 `wowsmod help ref.recolor`); 纹样顺船体走向, 不用规则网格; 单靠细线不算图案; 发光只做点缀, 面积上限写进设计语言卡。
