# workflow.review: 每层复盘(工作流优先)与审美评审
上级: workflow
下级: 无
---
**何时**: 每层结束、每轮方向预览后、验收后。结论写回对应节点并记 `workflow.changelog`。
**A. 陌生 AI 视角**(假设只拿到 AGENTS.md + `wowsmod help`): ①哪一步不知道该干什么/该读哪个节点? ②哪里靠了临时手工或一次性脚本? ③完成标准能不能客观判定? ④哪些重复动作该沉淀成命令/模板/脚本? ⑤有没有写死船名/角色/路径? ⑥主题模式有没有把「有 3D 模型」理解成必须立人像(错→涂装+道具外带件)?
**B0. 对标**(有例子必做): `workflow.layers.map.benchmark`; 任维<3 → 本层不通过。
**B. 审美评审**(工作台图 + 港口图各看一遍, 每项 好/一般/差 + 一句理由): 整体构图与主次; 比例与外带细节(倒角/镶边/发光线, 非光坨); 色彩(量化占比/明度差/非脏灰糊)与主题一致; 主题辨识度(远景认得出); 发光适度; 远近昼夜可读。
**C. 追溯**: 任一项"差" → 找到是哪层/哪个节点没引导对 → 改那个节点(通用底线进主 skill, 审美偏好进风格包), 而不是只修这个 mod。mod 质量与工作流改进冲突时, 优先工作流。
**记录**: changelog 一行: 日期 | 层 | 差在哪 | 根因(分析不足/工具缺能力/执行偏差/验收太松/引导缺失) | 怎么补 | 效果。
