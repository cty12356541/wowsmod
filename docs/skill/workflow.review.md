# workflow.review: 对照意图与证据的复盘
上级: workflow
下级: 无
---
**何时**：有实质变化的小样、相关制作层结束或验收时；轻量修正只核对受影响项。
**先看图**：参考与本项目用同机位、同显示范围并排；说明 look、昼夜、距离、构建与船。没有港口图就标“仅工作台”，不能补写实机结论。
**逐项判断**：构图主次/轮廓比例；图案与主题辨识；明暗色彩及材质；发光是否遮掉细节；远近可读与动作/碰撞。关闭发光再看涂装本身。对标方法见 `workflow.layers.map.benchmark`；数字辅助定位差距，判定依据是已选意图，不设通用色彩/占比/评分门槛。
**区分证据**：文件哈希完好只说明文件；注册日志只说明加载注册；截图证明该视角可见；动画还需时间序列。未测场景与未知能力逐项列出。
**记录到项目**：意图 → 观察 → 差距 → 原因假设 → 修改 → 新证据/未决项。退回对应层修正，避免只写“好看/已修复”。
**改进指引**：重复出现且能跨项目复用的问题才提为工具/skill 改进候选；案例参数保留在案例。每轮制作无需改全局 skill。历史节点与案例路径见 `workflow.changelog`。
