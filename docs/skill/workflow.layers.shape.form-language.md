# workflow.layers.shape.form-language: 外带造型语言
上级: workflow.layers.shape
下级: 无(精修往返: `workflow.layers.shape.blender`)
---
**何时**: 设计书写外带件之前; 对标含翼/环/刀/饰板的例子或原包网格。CLI 粗挂之后、Blender 精修之前先过本节点。
**目标**: 先定**造型语言**, 再进 Blender; 禁止「无倒角光坨/细杆」充数。

**从例子拆(视频帧或原包 .geometry)**:
1. **剪影**: 远景能认出的外轮廓(刀翼弧、环+刺、饰板梯形…); 画 1 张剪影对比。
2. **分件层级**: 根/杆/头/镶边是否分开或假分件(材质/色带暗示)。
3. **倒角倒边**: 外轮廓是否软边; 锐边只留在切割面。
4. **镶边/厚度**: 边缘有无第二圈线或实体厚度(非纸片)。
5. **比例**: 最长边 vs 船长、船宽、干舷(通常 ≪2% 船长; 大翼例外须设计书特批)。
6. **细节密度**: 近景有分层/螺钉感或贴图纹; 远景不花。
7. **材质分区**: 金属/漆面/发光条是否分材质或分 UV 岛。

**主题约束**: 只道具形; 禁人物雕像。可 PMX 拆道具再按上表补倒角镶边。

**流程**: 对标表 → 草图/简化 glb → `shape.blender` 精修 → import 验收(不穿模、剪影对、细节达标)。
**完成标准**: 每个外带件有剪影+层级+尺度一行; 工作台 side/stern 近景能看出倒角或镶边; 对标外带维≥3。
**自评**: 缩到 128px 宽还有道具剪影吗? 还是只剩光点?
**外带翼/羽**(参考区间): 挂点 舷楼高 40–60%; 片厚 ≈ 羽宽 8–10%, 尾端更薄; 详见 `shape.refine.layout`。
