# workflow.layers.shape.refine.teardown: 拆标杆船模改动
上级: workflow.layers.shape.refine
下级: 无
---
**输入**: 标杆视频/帧(dense 1–2s)、已有 ANALYSIS。
**产出**: 改动表 + 标注图(红框几何区)。必列: 外带大件 / 罩壳改轮廓 / 小饰件 / 发光几何 / 动画。
**每行字段**: 名称 | 类型(外带/罩壳/改型) | 挂点 | 尺度(相对船长/船宽/舰桥) | 随炮转? | 动画 | 证据帧。
**做法**: 1) dense 帧按视角分类(舷/斜/俯/夜/近); 2) 标注图标出翼/环/艏饰/炮塔壳等; 3) 对照原版勃艮第剪影差(侧视+俯视各一张)。
**完成标准**: 表≥4 行大件; 每行有证据帧路径; 明确「完成度多少来自几何」。缺公开包时挂点写「推断, 装包后 `model list` 核」。
**禁**: 只写「有翅膀」无尺度/挂点。
