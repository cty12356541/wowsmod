# workflow.layers.ref.assets: 素材获取与记录
上级: workflow.layers.ref
下级: 无
---
**目标**: 每份素材可追溯、规约已知。**输入**: 角色/作品或参考链接。**完成标准**: ASSETS.md 每项有来源/本地路径/规约要点/sha256(整包)。
- 模板: `wowsmod design-template assets` → `ASSETS.md`。每项: 来源 URL、用途、分辨率、许可/规约原文要点、本地路径。
- 立绘/设定: 官网与官方媒体 → 官方 wiki → 社区 wiki(如 BWIKI、Fandom)→ 官方社区(米游社等)。存原图, 不截缩略图。
- 官方模型(MMD/PMX 等): 只取官方账号或明确允许改造的免费资源; 读并抄录使用规则(常见: 禁二次配布、禁商用、版权归原厂)。需登录的交用户或在用户已登录的浏览器里下载; 付费资源不买, 报告。
- 原 mod 链接: 视频简介、置顶评论、作者主页。
- 压缩包中文名常是 GBK 编码, 解压时按 GBK 解码; 整包记录 sha256。
- 素材只本地用: 不进仓库、不分发; 设计书与打包说明里写明规约。
