**目标**: 拿到足够证据, 能不看参考说出每个部件长什么样。
**输入**: 用户给的参考/角色; 按模式见 `workflow.replicate|theme|original`。
**产物**: `ASSETS.md`(来源/用途/分辨率/许可)、参考图集目录、(复刻)关键帧拼图与 TEARDOWN.md、(主题)设计语言卡草稿。
**完成标准**: 复刻按目标覆盖多角与相关部件, 昼夜/开火只在参考涉及且可获得时收集, 缺视角标未知。主题素材有来源与规约。原创有关键词/用途与小样依据, 方向未明才出候选。多个参考写明选择理由(设计意图、素材与能力)。
