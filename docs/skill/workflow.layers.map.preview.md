# workflow.layers.map.preview: 最小方向小样
上级: workflow.layers.map
下级: 无
---
**目标**：用最少制作验证方向差异与风险。复刻先一个粗样对照参考；主题/原创只有方向未明确时才做少量实质不同候选，已有选择就执行，不强制三档。
**输入**：独立基础项目、部件计划、来源色板与待解决问题。
**命令**：`wowsmod design-preview <spec.toml> --init` 写示例；填写 base/out、vars 与 direction steps 后 `wowsmod design-preview <spec.toml>` 复制基础项目、执行步骤并出图。示例中的船、色号、候选数量与步骤都要按任务删改；`--only`/`--render-only` 见 help。
**步骤范围**：先大面色与一处关键图案；模型或发光只有设计涉及且需验证时才加。steps 是会执行的命令，审查后仅保留项目编辑/出图，不放 install/apply/游戏启动命令。方向预览不授权安装。
**有意义的差异**：构图、色块关系、图案语言或模型轮廓的选择，写清意图与取舍。主题角色提供设计语言，不用人物雕像制造差异。
**检查**：同机位图、远景缩略图与受影响部位近景。比较是否表达各自意图，不按统一像素宽/数量打分。小样与 spec、未验证能力和选定方向写入 §4；需要多方案持久管理时见 `ref.variants`。
