# workflow.book: 设计书(三模式共用)
上级: workflow
下级: 无
---
**目标**: 一份让用户能拍板、让执行层能逐项对照的设计书。
**输入**: 模式节点的第 1 步产物(素材、设计语言卡/参考分析)。
- 命令: `wowsmod design-book init <项目> --mode <模式> --title …` / `check` / `revise --note "<用户意见>"` / `finalize --by 用户`(只在用户明确说定稿后)。未定稿时执行类命令会提示。
- 模板: `wowsmod design-template book|assets|analysis|breakdown|acceptance`(设计书/素材清单/参考分析/拆解清单/验收清单)。
- 结构: §1 来源 · §2 设计语言卡(含「采用的风格包」)· §3 逐部件映射(含额外模型、特效) · §4 方向预览 · §5 执行偏差。
- 设计书 = 层 1–2 的产物 + 方向预览; 定稿后每层对照 §2–§3 自查, 偏差记 §5; 改了设计就 `revise` 并重新定稿。
- 用户没空定稿时: 可先按一个方向做"未定稿第一版", 在设计书与汇报里明确写"未经用户定稿", 其它方向保留预览。
**完成标准**: `design-book check` 无缺项; §4 有方向图; 待用户决定的事单列一节。
