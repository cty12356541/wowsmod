# workflow.book: 设计依据、小样与选定方向
上级: workflow
下级: 无
---
**用途**：整套制作保留一份可执行、可核验的设计书；简单编辑用项目记录即可。
**命令**：`wowsmod design-book init <项目> --mode <模式> --title "<标题>"`；`wowsmod design-book check <项目>` 检查结构；`wowsmod design-book revise <项目> --note "<意见>"` 记录改动；用户明确选择/定稿后 `wowsmod design-book finalize <项目> --by 用户`。结构检查通过不代表用户认可或视觉验收通过。
**模板**：`wowsmod design-template book|assets|analysis|breakdown|acceptance`。
**内容**：§1 需求、来源与授权范围；§2 设计语言及依据(风格包可选)；§3 本次涉及的部件/图案/材质/发光/模型、可行性与验收项；§4 小样、方向差异和选择依据；§5 实施偏差、构建/船/港口、检查证据与未决项。
**小样**：复刻先做一个对照粗样；主题/原创仅在方向不明确时提供少量有实质差异的候选，不为凑数量重复出图。没有模型改动就跳过造型层。
**执行**：已有明确需求与选择时直接推进。方向仍待决定时可在项目里保留标明“未定稿”的小样，不伪造用户定稿，不用环境变量绕过检查。实质改变已选设计时记录 revise 与新选择；完成前逐项核对 §3。
