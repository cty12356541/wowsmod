# workflow.layers.verify.port: 获授权后的港口验收
上级: workflow.layers.verify
下级: 无
---
**前提**：确认本次允许应用/安装、启动游戏、进港及测试后保留或撤回的范围。选择设计方向或历史训练房授权不能替代这些授权。未获授权时提交工作台证据与待验清单。
1. 游戏关闭时先 `wowsmod apply <项目> --dry-run`，确认客户端/构建与当前→新方案；按授权应用，再 `wowsmod installed --verify`。这只检查登记文件，不证明注册或画面。
2. 在获准启动后记录船、客户端构建、港口、时段、画质、方案修订和机位。Windows 可用 `python scripts/port/port_shot.py`；先查看其帮助与当前界面，不照抄历史固定坐标或时长。
3. 按改动选择舷侧/艏斜/艉斜/俯视/近景/远景；涉及发光再拍可比夜景。切换港口前记原设置，拍后还原；不进入未授权的战斗/训练房。
4. 查 `profile/python.log` 的 `registerShipMod … done` 与新增错误，这是注册证据。截图证明该角度可见；动画需相隔数秒的同角截图/视频，检查方向、速度与位置，不能凭单帧或采样日志判通过。
5. 对照参考/工作台/港口，记录差距与未测项。按约定关闭游戏、保留或撤回应用，使用登记操作，不手删资源；同船切换撤回需明确选择原方案。
**完成**：本次验收项有文件/注册/视觉各自证据，未知项未冒充通过，港口设置和安装状态符合约定。亮度/面积测量可辅助诊断，不把 P5 的过曝阈值作为全船通用标准。
