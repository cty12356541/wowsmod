# workflow.theme: 主题设计(用户给角色 + 作品)
上级: workflow
下级: 无
---
**目标**: 从角色提炼设计语言, 用**船体涂装 + 少量外带装饰件**表达主题; 与用户迭代设计书后执行。
**输入**: 角色名 + 作品名、目标船(`wowsmod find <关键字> --ship`)、风格包(没有就从 `wowsmod help styles` 推荐)。
**主题表达手段(硬规则)**:
1. **角色只提供设计语言**: 配色、纹样、道具意象、材质气质。立绘/设定/官方模型是参考, 不是往船上搬的立像。
2. **船体表达** = 贴图合成(`ship-color` / `tex recolor` / `bake-ref` / `tex composite` / 键色图案) + **少量外带装饰件**(翅膀饰板、麦克风/羽毛/音符环、徽章板等**道具形**几何)。
3. **禁止**把角色全身/半身/头身 PMX 或人物 mesh 作为雕像挂到船体(甲板/舰桥/炮塔顶都不行)。PMX 可继续本机拆 UV/取色/只导出道具部件(麦克风、天環、耳羽…), **人体材质不得进 ship 装配**。
4. 没有可用道具 3D 时: 用简化几何或纯贴图表达, 并告诉用户; 不得用人体模型凑数。
**第 1 步(设计书 §1–§2)**:
1. 素材: 官方立绘/设定/模型(`workflow.layers.ref.assets`), 注明来源与规约; 优先官方。
2. 设计语言卡: 主/辅/点缀色及面积(`scripts/ref/palette.py`), 标志元素(道具/纹样/符号), 线条与材质; 每项写依据图。
3. 映射到船(§3): 逐部件写大面配色、图案、发光、**外带装饰件**(形状/挂点/尺寸, 禁止人物雕像行)、特效。
4. 方向预览(§4): 克制 / 主题强化 / 夸张, 差异是涂装密度与外带件数量/尺度, 见 `workflow.layers.map.preview`。
**完成标准**: ASSETS 有来源+规约; 语言卡有依据; §3 无「人物雕像」行; §4 三方向图已出; 受限素材已写明。
**社区对齐**: 高质量主题船常见路径是「官方 UV 重画 + 角色纹样/徽章/道具形外带件」, 不是立人像; 流萤等含人物包属复刻定制例外。方法索引 `learn.makers`。
