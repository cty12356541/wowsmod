# workflow.theme: 主题设计(用户给角色 + 作品)
上级: workflow
下级: 无
---
**目标**: AI 主动提炼角色的设计语言, 与用户迭代设计书, 定稿后执行。
**第 1 步(设计书 §1–§2)**:
1. 素材: 官方立绘/设定图/官方模型(`wowsmod help workflow.layers.ref.assets`), 每张注明来源; 优先官方, 不手绘插画级图案。
2. 设计语言卡: 主/辅/点缀色及面积比例(从立绘取色: `python scripts/ref/palette.py <图>`), 标志元素(道具/纹样/符号), 线条与材质风格; 每项写依据图。
3. 映射到船(§3): 逐部件写大面配色、图案、发光、人物/道具模型(位置与尺寸)、是否加翼/光环、特效是否随主题。
4. 方向预览(§4): 克制 / 主题强化 / 夸张, 见 `wowsmod help workflow.layers.map.preview`。
**自评**: 只看远景截图, 熟悉作品的人认得出是谁吗? 有没有只用了主色而丢了标志元素? 素材规约(禁商用/禁二次配布)写进设计书与打包说明了吗?
