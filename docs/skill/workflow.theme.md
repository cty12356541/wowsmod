# workflow.theme: 主题设计(用户给角色 + 作品)
上级: workflow
下级: 无
---
**目标**: AI 主动提炼角色的设计语言, 与用户迭代设计书, 定稿后执行。
**输入**: 角色名 + 作品名、目标船(不知道 SDK 名: `wowsmod find <关键字> --ship`)、用户偏好的风格包(没有就从 `wowsmod help styles` 推荐一个)。
**第 1 步(设计书 §1–§2)**:
1. 素材: 官方立绘/设定图/官方模型(`wowsmod help workflow.layers.ref.assets`), 每张注明来源与规约; 优先官方, 不手绘插画级图案。**没有可用 3D 模型**(无官方模型或规约不许改造)→ 不做人物模型, 改用立绘贴图 + 标志道具(能自建的简单几何), 并告诉用户。
2. 设计语言卡: 主/辅/点缀色及面积比例(`python scripts/ref/palette.py <图>`), 标志元素(道具/纹样/符号), 线条与材质风格; 每项写依据图。
3. 映射到船(§3): 逐部件写大面配色、图案、发光、人物/道具模型(位置与尺寸, 尺寸用米写, 见 `ref.model.import` 的单位换算)、是否加翼/光环、特效是否随主题。
4. 方向预览(§4): 克制 / 主题强化 / 夸张, 见 `wowsmod help workflow.layers.map.preview`。
**完成标准**: ASSETS.md 每项有来源+规约; 设计语言卡每项有依据图; §3 每个可见元素一行; §4 三方向图已出并交给用户; 受限素材已写进设计书。
**自评**: 只看远景截图, 熟悉作品的人认得出是谁吗? 有没有只用了主色而丢了标志元素? 素材规约(禁商用/禁二次配布)写进设计书与打包说明了吗?
