# workflow.layers.fx: 全局特效与验证边界
上级: workflow.layers
下级: 无
---
**何时**：设计明确需要改特效时；不要求每个船主题都动特效。粒子贴图往往全局共享，会影响其他船，先列范围，宜用独立 loose 项目便于管理。
**路径**：`fx find --kind <类型>` → `fx ship-effects <船>` 查挂点/粒子 → `fx init <项目> --from <主题.json>` → `fx apply <项目>`。参数以 help 为准；先分辨颜色图与数据贴图，不能直接乘色所有资源。
**能力**：历史港口 Smoke_* 换色可见，但 Robin_FX 战斗对照的烟仍与原版接近，未证明通用烟色可改。foam* 是数据图，当前贴图乘色方法不能据此控制航迹颜色；LM/MVEA 等数据含义与发射器参数也不能当普通 RGB。未知构建需重新核对，不把预览染色当游戏能力。
**预览**：game-day/night 下可用 `--query "env=water&speed=full&warm=20"` 观察已支持的烟/水面效果，`fx=vanilla` 作预览对照；缺骨骼/模拟数据时说明近似或不可用。
**实机**：港口与战斗可能不同。只有本次用户明确授权训练房/开火时才测试，历史授权不继承。按原版与方案同机位对照，保护可读性，结束按约定恢复，不手删受登记管理的资源。
**完成**：项目记录影响文件、方法、已验证场景、未生效/未知项与证据。历史 2026-10-14 Robin_FX 细节和参数假设见 `workflow.changelog`，不宣布贴图之外的新能力。
