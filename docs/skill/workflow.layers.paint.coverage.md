# workflow.layers.paint.coverage: 按设计核对贴图覆盖
上级: workflow.layers.paint
下级: 无
---
**输入**：本次目标、目标部件清单、参考/选定小样与贴图项目。
**逐项检查**：船壳/水线/水下、主甲板、上层/烟囱、炮塔顶侧座圈/炮管、副炮/高炮、指挥仪/雷达、格栅/网/锚。只检查计划涉及及受影响区域；有意保留原版色可注明，不要求全船重涂。
- 普通换色区确认迷彩遮罩不会覆盖新色；发光区的 `_mg` B 留给 glow，不能全船一刀清零。
- 图案清单齐全，数量/覆盖与参考或设计一致；复刻容差由该项目定义，不以统一百分比判所有风格。
- 同机位对比，含主图案远景与关键近景；关闭发光仍能看懂涂装。共享 UV、甲板背面、炮管和格栅注意错色楔、白三角、拉伸与锯齿。
- 有量化需求时用一致遮罩/分类比较 `role_share`、色差与亮度，连同方法和误差记录；不设白/主色/暗色的通用面积门槛。
- 港口检查按授权补充；只有预览时不写实机通过。原有 P5/P6 数值与分类尝试见 `workflow.changelog` 案例归档。
**完成**：计划部件逐项有证据，偏差与未验证项清楚；无需为简单换色补齐不相关的模型/主题层。
