# workflow.replicate: 复刻参考视频或图片
上级: workflow
下级: 无
---
**目标**：先证明参考做了什么，再复现。输入为参考文件/链接、目标船与允许的使用范围。
1. 读 `workflow.layers.ref.video`，抽取有时间戳的多角关键帧，放大船艏/船艉/甲板/炮塔顶与只短暂出现的特效。只有截图就标缺失视角，不猜封面看不到的模型。
2. 有合法可读的公开包时用 `workflow.layers.ref.teardown` 只读拆解；记录来源、许可与无法确认的内容。未获再发布授权时 `wowsmod mod license <项目> --note "复刻自 <作者/链接>，未获再发布授权"`。
3. 在设计书逐项对应证据帧、部件、数量/覆盖与可行性。先出一个复刻粗样，按同机位与参考并排；方向已有依据时无需另造三档。
4. 按 `workflow.book` 记录选定方向，仅做相关层。图案需描摹时用 `bake-ref`；收尖笔触不能用等宽程序线代替。新增模型、非对称与动画都由证据决定，不能自行补成“看起来像”。
5. 工作台同角对比轮廓、图案、材质、发光，再按授权做港口证据；未安装/未进港就写相应阶段未验证。
**完成**：清单达成，或逐项说明差距、缺证据/缺能力及可选后续。连续迭代无改善时先诊断，不凭固定轮数宣布成功，也不绕过设计检查。
