# workflow.replicate: 复刻模式(有参考视频/图)
上级: workflow
下级: 无
---
**目标**: 拆解书(= 设计书, `design-book init --mode replicate`)写清"参考做了什么", 再按层复现。
**输入**: 参考视频/图链接、目标船。**完成标准**: 见下方停止条件。
**第 1 步差异**: 必须拿到视频并抽帧(`wowsmod help workflow.layers.ref.video`); 有公开 mod 包就只读拆解(`workflow.layers.ref.teardown`), 它直接告诉层 3–5 要做什么。
**许可**: 复刻别人的 mod 只做本机自用; 立项时 `wowsmod mod license <项目> --note "复刻自 <作者/链接>, 未获再发布授权"`, pack 会默认拒绝。
**预览**: 只出 1 个复刻粗样(`design-preview` spec 写一个方向), 与参考帧同机位并排(`scripts/ref/compare.py`)。
**定稿**: 参考本身就是设计依据; §1–§3 每项都有证据帧/放大图、数量与覆盖率已量、不能做的已标出, 即可先执行(`WOWSMOD_BOOK_IGNORE=1`), 同时交用户复核, 通过后 `finalize`。
**各层差异**: 层 2 逐帧找只在某几秒出现的模型/特效、两舷不对称、俯视图案; 层 3 新物件位置用 render JSON 的 `frame` 换算; 层 4 按参考帧**描摹**(`bake-ref`), 不自己发明条纹; 层 7 三联图: 参考帧|工作台|港口。
**停止条件**: 拆解清单全部达标; 或 3 轮后剩余差距都标"缺能力"并告知用户。
**反例**: 只看封面 → 漏掉甲板/炮塔顶图案与发光船壳; 用程序等宽线代替收尖笔刷 → "完全不一样"。有没有额外模型必须看帧, 不能猜。
