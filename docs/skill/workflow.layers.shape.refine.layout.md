# workflow.layers.shape.refine.layout: 布局与尺度推导
上级: workflow.layers.shape.refine
下级: 无
---
**用途**：从主题与船体关系确定布局，不抄案例挂点/翼展/厚度。
**方法**：先定视觉中心与主次；对照船长、船宽、干舷、甲板和炮塔活动范围画俯/侧剪影。用工作台或简化 glb 比较有实质分歧的候选；已有方向就直接检验它，不要求每次另做多档。
**自问**：布局是否有意图？大件会互抢或重心偏移吗？远景轮廓是否表达主题？近景连接和材质是否可信？是否意外遮住炮口、烟囱或功能部件？对称/不对称是否出于设计？
**形状**：需要羽翼时研究骨架、根部衔接、弯曲、收尖、分层与厚度；需要装甲/环/徽记时用对应语言。结构连接与悬浮都可以是设计选择，写明取舍；不给所有题材预设羽翼或悬浮核心。
**测量**：`scripts/model/sil_pair.py`、`layout_measure.py` 可辅助剪影与比例对比。数值是相对本船/意图的记录；碰撞检查需含炮管仰角与回转包络，有意贴合船体与意外穿模分开。
**历史**：布洛妮娅标杆区间、Robin P5/P6 肩甲/浮翼与 C2 尝试保留于 `workflow.changelog` 所列归档，构建与部分港口未知。动画建议须先看 `ref.model.animate`，不因布局可行就认定挂载可靠。
