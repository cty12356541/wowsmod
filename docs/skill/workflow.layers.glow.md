# workflow.layers.glow: 发光遮罩与材质
上级: workflow.layers
下级: 无
---
**何时**：设计需要自发光时才执行。输入是指定区域、颜色/材质意图与项目；命令和机制见 `ref.glow`。
**步骤**：确认贴图、mfm 与 visual identifier → 看遮罩叠加图 → 小面积试验 → 同角检查日/夜、近/远和关闭发光的涂装。遮罩由图案或 lineart 等生成，按当前项目修订更新，不沿用未经核对的旧遮罩。
**判断**：大面积微光与局部强光各有用途；power、B 值、色号、线宽都由本设计小样决定。检查高光是否糊成一片、主题色是否丢失、远景细线是否消失；不规定统一强度、面积或核心色。
**自定义部件**：先验证静态装配可见，再逐件查发光。工作台 emissive 通道、文件/材质参数、注册日志和港口夜景是不同证据；“受光变亮”不能当成“自发光”。节点/identifier/法线问题仍可能存在，不照抄 C2 的挂点修改当通用解法。
**完成**：只有计划区域发光，细节和轮廓仍可读，参数与验证场景记录在项目；未进港则标仅预览，缺能力就保留限制。Robin r22/r34/P5.1/C2 原始尝试与未解决的光环问题见 `workflow.changelog`，不是默认参数。
