# workflow.layers.paint.color-logic: 配色逻辑(量化+分区)
上级: workflow.layers.paint
下级: 无(工具: `scripts/ref/palette.py`、`scripts/ref/color_logic.py`、`port-albedo`)
---
**何时**: 层 2 语言卡 / 层 4 底色前; 对标例子或主题立绘已齐。勿只抄几个色号。
**目标**: 写出可执行的**搭配逻辑**(占比、明度层、冷暖/饱和、色相距离、船体分区、点缀位、发光与底关系、远景可读、港口补偿)。

**步骤**:
1. **量化取色**: `palette.py` 对立绘+例子关键帧各出 5–8 色(hex/占比/L*/sat)。
2. **分角色**: 标 主(≥50% 或≈60)、辅(25–35)、点缀(≤15); 再标 **深/中/浅** 三档(各档管什么: 深=压边/水线/结构缝; 中=上层或色带; 浅=船壳大面)。
3. **关系**: 记冷暖(暖底冷辅等)、饱和差、色相(邻近/互补/分裂互补, 用色相环目测+写一句)。
4. **分区表**(必填): 船壳 | 水线/干舷带 | 甲板 | 上层/烟囱 | 炮塔 | 外带件 — 各用深中浅哪一级 + hex(屏上色)。
5. **点缀与发光**: 点缀放徽记/镶边/炮塔顶/外带边缘; 发光色 = 辅色或点缀的高明度版, 面积≪主色; 忌发光与底同明度糊成一片。
6. **港口**: 每个屏上色跑 `port-albedo` → 贴图 `--to-color`; 写入设计书。
7. **方案**: 用 `color_logic.py` 出 2–3 套分区预览+色板; 工作台并排后自选, 理由写占比与明度差。
8. **对标**: `map.benchmark` 配色维≥3。

**完成标准**: 有色板图+分区表+port-albedo 换算; 主辅点缀占比写清; 至少一档 L*差≥25; 远景 fq 能分出主/辅分区; 选定方案有一句理由。
**自评**: 去掉点缀后还剩角色向配色吗? 是不是脏青灰糊成一色?
