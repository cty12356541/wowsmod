# workflow.layers.paint.color-logic: 从参考推导配色与分区
上级: workflow.layers.paint
下级: 无
---
**目标**：解释色彩为什么在这些部件上，而非只列色号。简单换色保留目标色与选区即可；整套设计用下列方法。
1. 用 `scripts/ref/palette.py` 或 `part_colors.py extract` 从参考的具体部位取样，记录来源；别把背景混入角色主色。原创则记录选择意图，不要求角色来源。
2. 分出主/辅/点缀与亮/中/暗层，映射到船壳、水线、甲板、上层、炮塔及相关道具。主次由主题与轮廓确定，不要求白色主导，也不照抄另一项目面积。
3. 同角观察大色块、明度跨度、冷暖与材质。可用 `role_share.py`/`part_colors.py derive` 辅助分析，先核对分类和遮罩；测量结果是诊断线索，统一比例/亮度阈值不作验收门槛。
4. `wowsmod port-albedo "#1E3F66"` 是带引号的色号示例，可作已校准场景的初始换算，结果给 recolor 的 `--to-color`；构建/港口/光照变化后需复核，不保证所有暖色采用同一补偿。
5. 在 game-day、game-night 和关闭发光时检查色块与图案可读性，含甲板俯视及远景 mip；需要精确复刻才按参考记录数量/覆盖与本项目容差。

**完成**：色板来源/意图、部件分区、小样对比与选择理由齐全；最终观感按获授权港口证据补充，未做则写仅预览。P5/P6 的白占比、peri/royal 色号及提亮尝试移至 `workflow.changelog` 所列归档，不能套到其他主题。
