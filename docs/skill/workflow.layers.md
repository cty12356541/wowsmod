# workflow.layers: 七层执行总表(三模式共用)
上级: workflow
下级:
- workflow.layers.ref: 层 1 参考与需求(素材、抽帧、拆原包)
- workflow.layers.map: 层 2 映射/拆解清单 + 方向预览
- workflow.layers.shape: 层 3 大形与额外模型(道具外带; 精细改模见其子节点 blender)
- workflow.layers.paint: 层 4 贴图图案
- workflow.layers.glow: 层 5 发光与材质
- workflow.layers.fx: 层 6 特效(全局贴图)
- workflow.layers.verify: 层 7 验收(工作台 + 港口)
---
**规则**: 一层一层做; 每层产物写进设计书/项目, 自答该层"自评"; 未达完成标准不进下一层; 验收不达标退回对应层。三种模式共用这七层, 模式差异只写在模式节点里。
**出图**: 先 `wowsmod render --warm <项目>`, 之后每张约 1 秒; 检查图来自工作台/浏览器 render, soft 只量尺寸。

| 层 | 产物 | 完成标准(摘要) |
|---|---|---|
| 1 | ASSETS.md、参考帧/立绘/情绪板、拆包记录 | 按模式: 复刻=证据覆盖全船多角度/昼夜; 主题=素材+规约齐; 原创=关键词+方向图 |
| 2 | 逐部件清单 + 2~3 方向预览 | 每个元素有一行且标来源/命令 |
| 3 | 额外模型、部件改动(含 Blender 精修) | 剪影/位置/比例一致, 不穿模; 精细件已往返验收 |
| 4 | 完整图案贴图 | 关掉发光仍是"那套涂装" |
| 5 | 发光遮罩与材质 | 只在指定处发光, 占比在上限内 |
| 6 | 全局特效贴图 | 影响已评估, 能验证的已验证 |
| 7 | 并排对比、港口截图 | 清单逐项打勾 |
