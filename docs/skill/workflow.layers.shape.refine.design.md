# workflow.layers.shape.refine.design: 改型设计(剪影/比例/挂点)
上级: workflow.layers.shape.refine
下级: 无
---
**输入**: teardown 改动表; 角色设计语言(耳羽/环/乐器…); 船长(`mod set --ship-length`)。
**产出**: 方案表 + 剪影草图(俯+侧); 写入设计书 §3。
**对位法**: 标杆每件大改动 → 角色语言一件对等件(尺度同级, 造型换源)。例: 机甲翼→羽翼; 机甲炮塔壳→裙弧软壳。
**尺度**: 远景可读件翼展≳船宽或高度≳舰桥; 装饰小件≪船长 2%。挂点: 桅顶/舰桥侧/艏/炮塔(随转)分清。
**完成标准**: 俯+侧草图; 每件有源语言/挂点/尺度/是否随炮; 剪影主次清(主=翼+环, 次=艏饰+麦克)。
**禁**: 人物 mesh; 只有贴花认角色。
