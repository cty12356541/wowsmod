# workflow.layers.shape.refine.uv: UV 与贴图批次
上级: workflow.layers.shape.refine
下级: 无
---
**输入**：变换已应用的 glb、材质分区与项目设计意图。
**做法**：硬边拆岛，大面分配足够 texel；底色/图案/发光遮罩可分通道或贴图；需要细节再从高模烘焙 normal/AO。材质名、mfm 与导入映射核对一致。
**新网格图集**：共享图集可减少材质与便于改色，但尺寸/列数由项目决定；保留网格、图集、遮罩的批次标识/哈希与来源路径，一起导入。船体原版 UV 仍用相应 recolor/composite 方法，不硬套道具图集。
**往返检查**：用有方向标记的小样验证 Blender→glTF→导入→游戏的 UV 朝向与采样。可选择翻转安全图集设计，但不能把历史 v=0.5 当所有图集的唯一规则。修改布局后先查导入产物；按授权进港时再查近景，项目图集正确不等于已安装贴图就是该批。
**完成**：无意外拉伸/错采样，细节在目标距离可读，材质与批次一致；文件与实机证据分开记录。Robin T3/T3b/P5 的马赛克、镜像图集与旧路径混批原文见 `workflow.changelog`。
