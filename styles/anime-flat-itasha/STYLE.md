# 风格包: 二次元平涂痛涂(anime-flat-itasha)

## 适用
角色主题涂装(theme 模式), 或复刻流萤类"痛船"。不适合写实/军武风。

## 配色(实测: 流萤原包 Hull_a 8 色量化, 含 UV 空白, 只作比例参考)
| 角色 | 色 | 占比 |
|---|---|---|
| 底(浅) | #FFFFFF 白 | 21% |
| 压色(深) | #363939 深灰 | 20% |
| 中性暖 | #D8CCBC 米色 | 17% |
| 角色主色(暗) | #698D88 灰青 | 14% |
| 角色主色(亮)/点缀 | #7DE1D5 亮青 | 10% |
| 其余 | 灰 / 近白 | ~18% |
- 规则: 浅底为主(浅色合计 ≥ 50%), 一深一浅两档角色色, 深灰只做压边与分区, 不做大面积暗底(那是赛博霓虹)。
- 角色色从官方立绘取色(`wowsmod` 的 recolor/coverage 量), 不凭印象。

## 图案密度
- 大色块平涂(硬边、无渐变/少渐变), 色块尺度 ≈ 舷侧高度的 0.5–2 倍; 每舷 6–12 个主色块。
- 角色元素(流萤: 四叶花/蝴蝶结/翼脉纹)作为点缀, 每舷 3–6 处, 单个不超过舷侧高度。
- 立绘: 只放在甲板大块平面或炮塔顶这类大且平的面上, 每船 1–2 张; 立绘必须来自官方素材(ASSETS.md), 不手绘、不程序生成。
- 炮塔顶: 徽章 + 花纹(流萤 FGM049_a)。

## 发光比例(实测: 流萤 _mg)
- 大面积微光: 船体 B 最大 49/255、B>0 占 13%; 炮塔/人物最大 33。→ `glow --b-max 40`、`model import --b-max 33`。
- 局部强光只给小物件(流萤只有铃铛 B=255)。
- emissivePower 用着色器默认(不写), 局部强光件才写。

## 额外模型尺度
- 角色模型(PMX→`model pmx2glb`→`model import`): 站在艉部甲板上, 身高约 20–25 m(流萤: Stern 分段包围盒 y 最高 2.27); 用 `--height` 定尺寸, 远景剪影不能盖过上层建筑。
- 衣物/头发/薄片材质: doubleSided + alphaTest(流萤 alphaReference 150)。
- 道具(剑等)可做环绕/自转动画(`model animate`), 半径不超出船宽。
- 不要额外加几何"翼/光环"作装饰(反例: 我们 10-10 的翼+光环样例, 用户评价丑): 角色元素优先画进贴图。

## 命令参数(起点)
`tex composite`(色块/立绘合成进 _a, 官方 UV, 4096 必须带 mip)→ `glow --b-max 40 --mfm <船体/上层>` → `model pmx2glb` + `model import --height <h> --b-max 33`。

## 自评问题
1. 关掉立绘和角色元素, 还认得出是"这个角色"的配色吗?(配色比例对照上表, 差 ≤ 10 个百分点)
2. 远景只剩色块时, 船的剪影和分区是否清楚(深灰压边起作用了吗)?
3. 白天港口有没有整船发白(B 超过 50)?
4. 人物模型在远景是否仍在、是否比上层建筑还抢眼?
5. 立绘有没有被 UV 拉伸/切断?
