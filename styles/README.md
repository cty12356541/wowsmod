主 skill(`wowsmod help workflow`)只规定**通用底线**, 不规定审美。审美取向放在这里的"风格包"里, 设计书 §2 写明「采用的风格包」后再按包里的参数做; 没有采用任何包时只按通用底线。

通用底线只在 `wowsmod help workflow` 写一份(比例 / 不穿模 / 远近昼夜可读 / 发光适度), 所有风格包都要满足, 包里不重复。

## 结构
```
styles/<包名>/
  STYLE.md        # 必填各节: 适用 / 配色 / 图案密度 / 发光比例 / 额外模型尺度 / 命令参数 / 自评问题 / 正反例 / 来源
  examples/       # 正反例图(只在本机, 不入库: 见 .gitignore); STYLE.md 里写每张图的来源与想说明的点
```
- 数值尽量来自实测(`scripts/ref/coverage.py`、`scripts/ref/pack_teardown.py`、`wowsmod tex info`), 写明出处; 没有实测的写"经验值, 待验证"。
- 正反例图来自参考帧、原包拆解缩略图或我们自己的出图, 只本地保存; 原包与参考视频的版权归原作者, 不分发。
- 新增包(原创模式定下的风格想复用时也这样做): 复制一个现有包改写; 用过之后把"和预期差在哪"补进包里的「修订」节, 通用结论才升级进主 skill。
