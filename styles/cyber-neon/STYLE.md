# styles.cyber-neon: 风格包 赛博霓虹

下级: 无

## 适用
暗色科幻/霓虹风(如 Krillishna 类视频涂装)。不适合浅色角色痛涂。

## 配色(实测: 参考视频舷侧覆盖率, scripts/ref/coverage.py, 10-10 r2)
| 角色 | 色 | 占比 |
|---|---|---|
| 暗底 | #1C2027 | 61–79% |
| 中灰块面 | #50555E | 9–28% |
| 浅色 | #A2A5B0 | 2–5% |
| 发光 | #E2F0F8(近白偏冷) | 6–9% |
- 规则: 暗底为主; 中灰块面必须和暗底拉开(反例: #5C5F66 太接近底色, 港口看不出); 发光色是近白的浅色核心, 不是纯饱和色。

## 图案密度
- 主体是**有粗细变化、收尖、成组**的笔刷/流线(不是等宽程序线); 每舷 20+ 笔(反例 v3r1 只有约 8 笔)。
- 圆环/弧: 舷侧水线附近成组出现, 炮塔侧面圆环 + 横光条。
- 数量与覆盖率对照参考, 差 ≤ 20%(层 4 完成标准)。

## 发光比例
- 局部强光: 笔刷核心与圆环 B 满值, 面积占可见面积 6–9%。
- 炮管: 参考里整根发白光(放大图确认过), 按参考做, 不要凭印象改成细线。
- emissivePower 0.3–0.4 起试; 白天港口仍要看得出暗底, 夜间不能糊成一片。

## 额外模型尺度
- 参考无额外建模(抽帧确认); 同类其他参考有翼/光环/炮塔外壳——采用前必须有证据帧, 尺度不超过所挂部件的 1.5 倍, 且不穿模。

## 命令参数(起点)
清 `_mg` B(层 4 第 0 步)→ `tex composite`(笔刷图案)→ `glow --mask <笔刷键色> --power 0.35`(B 满值)→ `lineart --rings` 补圆环。
